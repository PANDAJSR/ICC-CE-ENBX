# 希沃手机 PPT 控制

已实现基于希沃白板手机端扫码的局域网配对，控制 CE 正在联动的 PowerPoint/WPS。与 EN 云课件的账号 IM 遥控分开：本功能不需要希沃账号或本机官方助手，手机与电脑需在可直接互通的 IPv4 局域网中。

## 使用

1. 更新插件，在 CE 中启用 PowerPoint/WPS 联动并开始放映。
2. 插件设置 →「希沃手机 PPT 控制」→「打开配对二维码」。
3. 使用希沃白板手机端扫码，进入 PPT 控制，测试上一页、下一页、指定页。
4. 可最小化配对窗口继续控制；关闭窗口停止监听并断开所有手机。二维码接受新连接的有效期为 15 分钟，过期后关闭重开生成新码。

使用系统分配的 TCP 端口，二维码内包含筛选后的 IPv4 地址及实际端口：排除常见虚拟/VPN 网卡、169.254 链路本地地址及 198.18/19 TUN 地址，优先带网关的网卡和 WLAN。配对窗口显示监听地址及 TCP/握手阶段。不修改防火墙；连接失败时检查电脑与手机网络是否隔离及 CE 的入站连接是否获准。日志搜索 `[SeewoPptRemote]`，记录 TCP 接入、模块/命令数字、握手拒绝原因及超时阶段，不记录二维码令牌和完整手机消息。尚未收到 TCP 接入只能说明连接未到达本服务，不能单凭此信息认定防火墙或手机侧故障。

## 实现与依据

静态研究目标：`SeewoIwbAssistant_0.0.3.1309`。详细研究在 `D:/Code/EasiNote-Resarch/topics/ppt-mobile-remote/README.md`。重写消息解析和 TCP 封装，没有复制官方程序集进入插件。新增 QRCoder 1.6.0 生成配对二维码。

- 帧头 `AA BB CC DD`，4 字节大端长度，UTF-8 JSON，最大 100000 字节。
- 外层 `{fromAppCode,messageId,traceId,content:{id,body}}`，响应保留 traceId。
- 公共模块 99999：9001/9002 握手，9003/9004 心跳，9007 断开，9009/9010 地址查询，9015/9016 支持模块查询。
- PPT 模块 3：9001/9002 协议协商，9003/9004 状态查询，9006 状态通知，1001/1002 上一步，1003/1004 下一步，1005/1006 指定页。
- 状态 0/1/2 为不可用/编辑/放映；页码从 1 开始。控制请求只在放映状态执行。
- 二维码使用官方 `https://r302.cc/d8WaY8` 结构，本地生成、不访问此 URL；不发布 IM UID，不支持跨网云转发及热点自动切换。

扫码握手要求匹配本窗口生成的短整型令牌，缺失也拒绝。未配对不得执行控制。限制最多四个 TCP 客户端、首个握手 15 秒、已连接空闲超时 45 秒。该令牌及明文局域网链路沿用协议结构，不提供强身份认证。相同命令 traceId 重发时重放回执，防止重复翻页。

控制通过宿主 `IPowerPointService.NextSlide/PreviousSlide/GoToSlide` 路由到 CE 现有 PPT 管理器，批注和页码继续依赖宿主放映事件同步。UI 调度前后校验演示文件，关闭窗口及插件卸载会取消未执行请求。PPT 信息每 500 毫秒读取一次，有变化后通知手机。

## 验证和限制

已通过包含图片、EN 遥控和 PPT 遥控在内的 82 项检查；PPT 部分涵盖握手令牌、协议、页码、重复请求、边界、编辑态拒绝、二维码编码、地址过滤、诊断，以及真实回环 TCP 收发和停止后断连。插件 Release 编译打包通过。

2026-10-23 真机连接日志确认手机先发送公共心跳 `99999/9003`，旧实现因未握手而拒绝连接。已按官方 `ClientManager.MessageDispatcher_BeforeDispatchMessage` 和 `OnHeartBeat` 的行为修复：握手前允许此心跳并回复 `9004`，随后继续等待公共握手；心跳不授予控制权限，也不延长首次握手的 15 秒期限。已增加真实 TCP 下先心跳、后握手和状态查询的回归检查。此次日志证明 TCP 可达及心跳顺序，尚不代表后续真机配对、控制均已通过。

尚未完成真实手机扫码界面、PowerPoint/WPS 放映控制与 CE 批注保留的端到端测试，不能据本地协议测试认定手机兼容通过。未实现手机远程开始/结束放映、缩略图传输或跨网连接。SDK 导航接口返回 void，当前成功回执表示已提交宿主调用，不能可靠获知底层 COM 是否成功；后续状态通知反映实际页码。SDK 未公开 Office/WPS 类型，当前 info.type 为 Office 默认值 0，WPS 控制仍使用宿主已连接的管理器，手机上品牌显示及兼容性需实测。
