# 课件弹出网页

课件资源卡通过 `window.open` 打开网页。插件接管 WebView2 的 `NewWindowRequested`，使用同一 WebView2 环境创建独立的 WPF 网页窗口，并通过事件 deferral 将新 WebView 返回给原始请求，保留浏览器原有的新窗口导航语义。

网页窗口设置 ICC-CE 主窗口为 Owner，并设置 `Topmost = true`，因此位于宿主批注窗口上方，也可参与宿主对所属子窗口的置顶管理。它不使用课件底层窗口的非激活样式，支持键盘输入、移动、缩放和关闭。网页内再打开的窗口使用相同处理。结束放映、隐藏课件或释放课件窗口时关闭所有网页窗口并释放 WebView2。

已使用真实 WPF + WebView2 临时验证程序调用 `window.open('about:blank', '_blank', 'noopener,noreferrer')`：确认新窗口可见、Owner 正确、Topmost 为 true，网页脚本能操作输入框，隐藏图层后弹窗全部关闭。

宿主人工验证：打开带网页资源卡的课件，点击打开；确认网页显示在 ICC-CE 批注层上方，输入框可以输入，拖动/缩放和关闭正常；打开第二层网页；结束放映，确认全部网页窗口关闭。切换普通桌面应用检查窗口层级。临时验证程序未加载 ICC-CE 的置顶维护器，不能替代完整宿主的窗口层级交互检查。
