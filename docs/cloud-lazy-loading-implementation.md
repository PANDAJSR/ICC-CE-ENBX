# 云课件懒加载首版

设置页的「云课件懒加载」默认开启并保存到 settings.json，下次打开云课件生效。关闭后播放仍经过原完整下载和打包流程。「下载到本地」始终完整下载。

插件获取实际详情版本后创建独立会话；WebView2 通过异步 deferral 提供 manifest 与逐文件同源路由。磁盘缓存按课件、版本及文件清单指纹隔离，下载写入会话独立 .part，长度和可识别 MD5 校验后原子提交。未知散列格式只进行长度校验，不跨会话复用该缓存。URL 遇到 401/403 时合并刷新，校验详情版本和全部路径/hash/大小后才更新 URL。

下载队列按路径合并任务，四个总槽，后台最多两个槽。相邻页预取为后台任务；前台请求可提升已排队的同一任务。当前首版只预取相邻页 XML，尚未进行空闲全课件/小图片预取。媒体支持从完整缓存提供单区间 206/416/HEAD；首次播放仍需下载该完整媒体文件，尚无网络分块缓存。

WebEasiNote 初始化只等待 manifest、Board.xml、存在的 Reference.xml 与第一页 XML。资源通过稳定 URL 独立补齐，图片具有加载状态和重试按钮，音视频不主动预载。页目录与正文存储分开；现有 Viewer 通过带 loadState 的目录投影获得页数/尺寸/预览，只有解析成功的页面才可提交。严格要求 Slide_0 起连续编号，每页核对正文 ID 与 Board 顺序；不符合时给出关闭懒加载的提示。

跨页保留旧画面，目标 XML 成功解析并在 React 提交后通知宿主。连续导航只允许最后意图提交，前端 40 秒取消，插件最多等 45 秒并发送取消消息。关闭会话取消其下载；旧 sessionId 的消息被插件忽略。增量页数组更新不会清空编辑补丁或全局栅格缓存。另存为会补齐清单后再导出。

```text

WebEasiNote: pnpm build
ICC-CE-ENBX: dotnet run --project tests/CloudLoading/CloudLoading.csproj
ICC-CE-ENBX: dotnet build --no-restore
```
